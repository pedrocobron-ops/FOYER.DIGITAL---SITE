Conexão

A chave que permite à Coxia gravar no site

Cole a chave de publicação — ela fica salva só neste navegador
Como criar a chave (o chefe faz uma vez e entrega à equipe):
github.com → Settings → Developer settings → Fine-grained tokens → Generate new token · Only select repositories: FOYER.DIGITAL---SITE · Permissions → Contents: Read and write.

Sem a chave dá para ver tudo; para publicar, aprovar ou mexer na equipe, ela é obrigatória.
